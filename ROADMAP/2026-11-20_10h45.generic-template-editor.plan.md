# Plan: editor genérico de plantillas (a partir de doomus-rs)

## Objetivo

Extraer el motor de emails de `doomus-rs/emails/_engine` a un proyecto independiente y genérico,
manteniendo la generación de plantillas Jinja2, y añadir un editor visual WYSIWYG.

## Motor

- Portar resolver / commands / guard / pipeline a `src/engine`, parametrizado por `templaitor.config.yml`
  (rutas, locales, salida, SMTP).
- Salidas: `.html`, `.txt` y `.subject.txt` por locale, con Jinja2 intacto.
- `compileSource()` puro (texto → resultado) para poder previsualizar borradores sin guardar.
- CLI: `compile [--watch]`, `editor`, `new`.

## Editor WYSIWYG

- Parser MJML propio y compartido (Node + navegador) que conserve comandos `$`, Jinja2 y comentarios.
- Modo diseño: compilar con `css-class="tpl-node--<id>"` en cada nodo para mapear el HTML real al árbol,
  envolver el contenido de `mj-text`/`mj-button` en regiones editables y convertir los tokens en chips.
- iframe con un script puente: selección, hover, edición inline, serialización DOM → fuente.
- Paneles: bloques + estructura (DnD), inspector de atributos/traducciones, ajustes de plantilla.
- Vistas: diseño, vista previa con datos de demo, texto, código.
