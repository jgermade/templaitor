# Plan: componentes reutilizables y rediseño de la interfaz

## Objetivo

Acercar el editor al diseño del visor de emails de referencia (barra con ruta, banderas, botón de envío,
asunto con conmutador `text`, datos de demo en editor oscuro y secciones plegables) y añadir un WYSIWYG
de componentes reutilizables.

## Componentes

- Carpeta `_components/<nombre>/` con `.mjml`, `.yml` (messages) y `.json5`.
- `$import(_components/<nombre>)` (carpeta → `<nombre>.mjml`); los textos del componente se cargan por
  defecto y la plantilla puede sobrescribirlos.
- Modo diseño: cada instancia se expande y se marca como un único nodo seleccionable (`tpl-comp`).
- Editor: abrir/editar componentes con el mismo WYSIWYG, insertar, convertir selección en componente,
  desvincular, usos por plantilla/layout.

## Interfaz

- Topbar: ruta como enlace + buscador de plantillas/componentes, banderas, botón SMTP con etiqueta
  configurable (`smtp.label`), abrir en pestaña nueva.
- Barra de asunto con avisos y conmutador `text`.
- Panel izquierdo: datos JSON5 (tema oscuro) + secciones plegables (Mensajes, Componentes, Bloques,
  Estructura, Plantilla). Inspector solo con selección.
