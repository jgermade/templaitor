# Resultado: editor genérico de plantillas

## Completado

- Motor portado y generalizado (`src/engine`), configurable con `templaitor.config.yml`.
- Nueva salida `<nombre>.<locale>.subject.txt`.
- Guard ampliado a `{% %}` y `{# #}`; el `.txt` ya no parte tokens Jinja2 al hacer wordwrap (bug heredado).
- Corregido `$if($lang === '…')`: `$lang` se sustituía antes de evaluar la expresión (bug heredado).
- `$t` con claves anidadas, avisos recogidos por plantilla/locale, detección de `$import` circular.
- CLI `templaitor compile | editor | new`.
- Editor Svelte 5: lienzo WYSIWYG sobre el HTML real de MJML, edición inline (textos traducibles o literales),
  chips para Jinja2/comandos, paleta de bloques, árbol con drag & drop, inspector, idiomas, asunto,
  vista previa con datos de demo, vista texto, vista código (incl. layouts/parciales/links), móvil,
  deshacer/rehacer, compilar y envío SMTP.
- Plantillas nuevas heredan variables/claves que requiere el layout.
- Proyecto de ejemplo (`examples/demo`) y tests (`npm test`).
