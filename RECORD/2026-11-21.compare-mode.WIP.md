# Template compare mode

Roadmap item `w4` of `ROADMAP/2026-11-20/project-plan.md`: code diff and visual diff between two templates
or two versions.

## 2026-11-21 · compare view

- New **Compare** view in the editor (all document kinds). B is always the current draft; A (base) is:
  the saved version, a git commit of the document, or another template / component / layout.
  Default: the saved version when there are unsaved changes, otherwise the last commit.
- Backend: `src/engine/history.js` — `documentHistory` (commits that touched the document's
  `.mjml`/`.yml`/`.json5`, via `git log -- <files>`, plus whether the files have uncommitted changes) and
  `documentAt` (the files at a commit via `git show rev:path`). `execFile` without a shell; revisions
  validated (`^[0-9a-f]{7,40}$`). Routes `GET /api/history` and `GET /api/version` in the editor API, so
  they also work per organization in the hosted service (fs storage; db storage has no git → no history).
- Each side has its own language and demo data ("Same demo data" uses B's for both). Both sides are
  rendered by the engine (`/api/preview`, `preview` and `raw` modes).
- Visual modes: side by side (iframes sized to their content inside one scroll container, so they scroll
  together), overlay (opacity of B), difference (`mix-blend-mode: difference`: identical pixels black)
  and swipe (`clip-path` + handle). Iframes are `sandbox="allow-same-origin"` (no scripts).
- Code diff: `@codemirror/merge` (MergeView) with tabs MJML · Texts · Demo data · Rendered text ·
  Compiled HTML; counts are changed blocks of lines (`Chunk.build`), not character changes (a first
  version counted characters: "4" for two changed lines). The draft side of MJML/texts/data is editable
  and ⇥ copies a chunk of A into the draft (through `store.update`, so undo works).
- Summary: subject (old → new), accessibility fails/warnings of each side, HTML size, attachments.
- Checks: engine test with a temporary git repository (history, version at a commit, other documents,
  invalid revision); `npm test` 30/30. In Chromium on a git copy of the demo with two commits:
  last commit vs draft → "No differences"; first commit → MJML 1 · Texts 2 · Rendered text 1 · Compiled
  HTML 4; reverting the two text chunks leaves Texts/Rendered text unchanged and the draft dirty; A in
  English vs B in Spanish; another template. axe-core: 0 violations in the side-by-side, swipe and code
  views after two fixes (a `<div>` inside the `<dl>` summary; the scrollable stage needed keyboard access).
