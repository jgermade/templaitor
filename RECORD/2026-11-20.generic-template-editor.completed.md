# Generic template editor (from doomus-rs)

## Goal

Extract the email engine of `doomus-rs/emails/_engine` into a standalone, generic project, keeping
Jinja2 template output, and add a WYSIWYG editor.

## Done

- Engine ported and generalized (`src/engine`), configured with `templaitor.config.yml`.
- New output `<name>.<locale>.subject.txt`.
- Guard extended to `{% %}` and `{# #}`; the `.txt` word-wrap no longer splits Jinja2 tokens (inherited bug).
- Fixed `$if($lang === '…')`: `$lang` was replaced before evaluating the expression (inherited bug).
- `$t` with nested keys, warnings collected per template/locale, circular `$import` detection.
- CLI `templaitor compile | editor | new`.
- Svelte 5 editor: WYSIWYG canvas over the real MJML output, inline editing (translatable or literal
  texts), chips for Jinja2/commands, block palette, drag & drop outline, inspector, languages, subject,
  preview with demo data, text view, code view (layouts/partials/links included), mobile view,
  undo/redo, compile and SMTP sending.
- New templates inherit the variables/keys required by their layout.
- Demo project (`examples/demo`) and tests (`npm test`).
- Makefile (`install`, `i`, `node_modules`, `test`, `up`, `build`), single-port dev server (API as Vite
  middleware) and public exposure through intergate (`make up GATE=host[:port]`).
