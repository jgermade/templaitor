# GitHub Pages: API reference (/api/) and in-browser editor demo (/demo/)

Plan: [`ROADMAP/2026-11-24/github-pages-api-and-demo.md`](../ROADMAP/2026-11-24/github-pages-api-and-demo.md).

## 2026-11-24 · /api/ and /demo/

- Request: "add to GitHub Pages /api/ — documentation of every endpoint — and /demo/ — the editor demo with
  the backend in the frontend (e.g. IndexedDB)".
- `/api/`: `site/api/index.html`, static and accessible (axe-core: no WCAG 2.1 AA violations, light/dark,
  desktop/mobile, no horizontal scroll). 64 endpoints: send API `/v1`, editor API `/api` (+ `/preview/:id`,
  `/static/:path`), `/auth`, `/orgs` (members, invitations, SMTP, API keys, send log) and `/healthz`; surfaces,
  authentication, roles, CSRF rule and error statuses. Each endpoint carries `data-route="METHOD /path"`;
  `test/site.test.js` compares them with the routes in the code in both directions.
- `src/server/server.js`: the JSON route table moved to an exported `createRoutes(project)` (behaviour
  unchanged; `createHandler` uses it); `previewPage` exported.
- `/demo/`: `editor/demo/` + `vite.demo.config.js` (`npm run build:demo` → `dist/demo`).
  - `shims/fs.js`: synchronous in-memory `fs` subset (exists/read/write/mkdir/readdir withFileTypes/stat/rm/
    rename/…) with change notifications; `vfs.js` loads it from IndexedDB at start and writes changes back
    (batched, flushed on `pagehide`); without IndexedDB it keeps working in memory.
  - `shims/node.js`: `child_process` (every program "not installed": git, WeasyPrint, Prince, veraPDF),
    `os`, `module`, `url`, `http`; `shims/globals.js`: `process`, `Buffer`. Aliases: `mjml` → `mjml-browser`
    5.4.1 (new devDependency), `nunjucks` → its browser build, `nodemailer` → stub.
  - `backend.js`: seeds `examples/demo` (bundled with `import.meta.glob`) into `/demo`, one "Initial version"
    per document; intercepts `fetch` for `/api/*` and `/auth/*` (`/auth/session` 404 → local mode) and
    answers with `createRoutes`; uploads go to the virtual fs; `/api/pdf`, `/api/pdf/validate`,
    `/api/attachment`, `/api/send` → 501 with an explanation; `/api/project` reports no PDF engine and no
    SMTP; `/static/…` URLs in previews become `data:` URLs; `POST /api/demo/reset` restores the starter.
  - `versions.js`: version store (same interface as git/db) in `/demo/.templaitor/demo-versions.json`.
  - `index.html` + `main.js`: banner (what runs where, links to the site and the API, "Reset demo" with a
    `<dialog>`), shareable preview at `?preview=<id>&lang=…`.
  - Editor: `editor/src/lib/host.js` — `previewUrl()` and `staticUrl()` overridable through
    `globalThis.__TEMPLAITOR_HOST__` (used by the store's `previewUrl` and `ImageField`); defaults unchanged.
- Site: `scripts/build-site.mjs` copies `dist/demo` into `dist/site/demo` (`--strict` fails without it) and
  stamps the version in the API page; `pages.yml` now installs dependencies and builds the demo; `build.yml`
  and `make site` too. Landing page: "Try the editor in your browser" button, Demo/API links in nav and footer.
- Checks: demo served under a sub-path (`/templaitor/demo/`, as on Pages) with Playwright: editor loads
  the three templates, preview with the logo as `data:` URL, edit → reload keeps it (IndexedDB), save a
  version (v2), compile, preview URL renders in a new tab, PDF tab shows the 501 explanation, reset restores
  the starter. `test/site.test.js` 2/2.
