# Reusable components and UI redesign

## Goal

Bring the editor closer to the reference email viewer (path bar, flags, send button, subject bar with a
`text` toggle, dark demo-data editor, collapsible sections) and add a WYSIWYG for reusable components.

## Done

- Components in `_components/<name>/` (`.mjml`, `.yml` messages, `.json5` demo data); `$import` of a
  folder; templates can override component texts.
- Component listing with usages (templates, layouts and other components) and root tag for placement.
- Standalone component preview using the `<mj-head>` of the preview layout.
- WYSIWYG: instances selectable as one block, double click to edit the component, back to the template,
  insert from the panel, turn the selection into a component (moves its texts) and detach (copies texts).
- Component parameters: `$import(path, key="value")`, `$param.name`, declarations in the component
  frontmatter (text, color, select, image, boolean), per-instance form in the inspector.
- Visual layout editing (`$content` shown as a slot) and layouts section in the picker.
- Redesigned UI (top bar, flags, SMTP button, open in new tab, subject + `text`, dark JSON5 data,
  collapsible sections, on-demand inspector), logo, `<dialog>` modals instead of browser dialogs.
- Local Mailpit (docker compose) served under `/mailpit/`, links to the sent message.
